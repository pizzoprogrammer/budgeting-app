🔍 HOW TO CHECK FOR ERRORS:
============================

1. Open DevTools (F12)
2. Go to Console tab
3. Look for any RED error messages
   → If none: ✅ Good
   → If any: ❌ Check error

4. Go to Network tab
5. Add a transaction
6. Look for API calls
7. Check if response is green (200)
   → If green: ✅ Good
   → If red: ❌ Backend issue
